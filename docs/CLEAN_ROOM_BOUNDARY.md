# Clean-room boundary

Application Foundry is a new implementation of common career-document and
application-tracking workflows. Historical archives were used only to identify
that the general problem remains useful. No historical source code, forms,
database records, organization names, templates, credentials, or user data are
included.

All examples use reserved or fictional names, addresses, organizations, roles,
URLs, claims, amounts, and dates. Existing archives remain read-only.
